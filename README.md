## 🚀 Quick Start

**Option 1 — Double-click to open:**
Just open `index.html` in any modern browser (Chrome, Edge, Firefox).

**Option 2 — Local server (recommended for full experience):**
```bash
# Python
python -m http.server 8080

# Node.js (if installed)
npx serve .
```
Then open: `http://localhost:8080`

## 🎯 Features Overview

| Feature | Description |
|---|---|
| 🧬 **Skill DNA Analysis** | Precise 1-5 level scoring with Critical/Moderate/Strong classification |
| 📊 **Gap Priority Score** | Weighted algorithm: gap × importance = what to fix first |
| 🤖 **ARIA AI Mentor** | Chat-based AI career mentor with personalized advice |
| 🎮 **Skill Missions** | Gamified tasks with XP, badges, and streak tracking |
| 🔮 **What If? Simulator** | Drag sliders to simulate readiness with different skills |
| 📄 **Resume AI** | Paste resume → AI extracts skills & role-match score |
| 🐙 **GitHub Analysis** | Simulated repo scanning for real skill evidence |
| 🏅 **Skill Evidence** | 3-tier proof: No Proof → Code → Deployed → Battle-tested |
| 🏆 **Leaderboard** | Student rankings by career readiness score |
| 👨‍⚖️ **Judge View** | Dedicated analytics dashboard for hackathon judges |
| ▶️ **Demo Tour** | Guided 7-step walkthrough of all key features |

## 🎤 Presentation Guide (For Judges)

### Recommended Demo Flow:
1. Open `index.html` → Landing page loads
2. Click **"▶ Watch Demo Tour"** for guided walkthrough
3. Click **"⚡ Analyze My Skills Free"** → Setup page
4. Click **"⚡ Generate My Skill Analysis"** → Dashboard
5. Walk through: **Skill DNA → Gap Analysis → Missions → ARIA Mentor → What If?**
6. Click **"Judge View"** in navbar → Platform analytics + scoring panel

### Key Talking Points:
- **Problem:** Students see "DSA Missing" — no context, no priority, no proof
- **Solution:** 🔴 DSA — Critical Gap | Required: 4/5 | Current: 2/5 | Gap: 40%
- **Unique:** Gap Priority Score, Skill Evidence system, What If? Simulator, ARIA AI chat

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5 + CSS3 + JavaScript (ES6+)
- **Styling:** Tailwind CSS (via CDN)
- **Charts:** HTML5 Canvas API (Radar Chart)
- **AI:** Simulated GPT-4 responses (ARIA Mentor)
- **No backend required** — fully client-side prototype
